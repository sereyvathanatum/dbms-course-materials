# References

- [MySQL 8.4 Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/): SELECT, data types, constraints, joins, CTEs, EXPLAIN, stored programs and privileges.
- [MySQL transactions](https://dev.mysql.com/doc/refman/8.4/en/commit.html): START TRANSACTION, COMMIT and ROLLBACK.
- [MySQL Connector/Python](https://dev.mysql.com/doc/connector-python/en/): connecting from Python and binding parameters.
- [mysql2](https://sidorares.github.io/node-mysql2/docs): connecting from Node.js and prepared statements.
- [MongoDB Manual](https://www.mongodb.com/docs/manual/): documents, CRUD, aggregation and data modelling.
- [Redis commands](https://redis.io/docs/latest/commands/): data types, EXPIRE and TTL.
- [Gilbert and Lynch (2002), Brewer's conjecture and the feasibility of consistent, available, partition-tolerant web services](https://doi.org/10.1145/564585.564601): the CAP theorem.
- [DBML](https://dbml.dbdiagram.io/docs/): the language used for the Week 7 ERD.
- [Cambodia administrative boundaries on HDX](https://data.humdata.org/dataset/cod-ab-khm): the course dataset.
