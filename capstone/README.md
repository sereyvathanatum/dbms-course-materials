# Capstone

Teams of 3–4 build one database project over the term. Use the course data or another public dataset (record its source and licence). No personal data.

Use one shared private repository; add teammates as collaborators.

| Week | Sprint |
|---|---|
| 1 | Team, problem, eight questions |
| 2 | Schema v0 and data dictionary |
| 3 | **Checkpoint 1:** proposal, data source, import |
| 4 | Five report queries |
| 5 | Joins; design problems found |
| 6 | Multi-step queries; peer review |
| 7 | ERD v1 |
| 8 | **Checkpoint 2:** normalized schema v1, migration |
| 9 | Midterm: plan next tasks |
| 10 | Views, procedures, triggers, permissions |
| 11 | **Checkpoint 3:** working app, parameterized queries |
| 12 | MongoDB part |
| 13 | Three pipelines; modelling decision |
| 14 | **Checkpoint 4:** Redis feature, demo rehearsal |
| 15 | Final demo, report, individual explanation |

Templates: `proposal.md` (CP1), `design.md` (CP2–4), `report.md` (final), `CONTRIBUTIONS.md` (who did what, with commit links). Add your own `schema.sql`, `import/`, `queries/`, `app/`, `results/`.
