# Submitting

1. Answers in `work.*`, labelled: SQL `-- Lab 3`, JavaScript `// Lab 3`, Markdown `## Lab 3`.
2. Output in `results/` (text or screenshots). Errors and empty results count; explain them.
3. Fill in `reflection.md`.
4. Commit and push:

   ```bash
   git add weeks/week-03
   git commit -m "Week 3"
   git push
   ```

5. Submit the commit link as your instructor asks (e.g. on the LMS).

Never commit passwords, personal data or peer evaluations.

**Check:** right question answered? Output sorted? Only `student_work` changed? Can a classmate rerun it?
