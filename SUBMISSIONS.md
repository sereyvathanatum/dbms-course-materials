# Submitting your work

1. Read the week's guide and run the worked example.
2. Write your answers in `work.sql`, `work.js` or `work.md`. Label each one with its task number, for example `-- Lab 3` or `-- Homework 2`, and keep lab tasks and homework in separate sections.
3. Save the output of your queries in the week's `results/` folder, as text files or screenshots. If a query gives an error or an empty result, save that too and explain it.
4. Answer the questions in `reflection.md`.
5. Check your changes with `git status`, then commit and push:

   ```bash
   git add weeks/week-03
   git commit -m "Week 3 lab and homework"
   git push
   ```

6. Submit the way your instructor asks, for example by posting the link to your commit on the LMS.

Do not commit passwords, personal data or peer evaluations. Send peer evaluations privately to your instructor.

## Before you submit

- Does each query answer the question that was asked?
- Is the output sorted, with a code as the last sort column?
- Did you change only tables and collections in `student_work`?
- Could a classmate run your work and get the same result?
