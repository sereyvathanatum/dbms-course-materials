# Week 15: Capstone presentation and handover

> Printable version: [README.pdf](README.pdf)

**Learning outcomes:** CLO1–CLO6

## Lesson

A good demo starts with a question, says where the data comes from, then shows the query and its result. Explain why your schema and database choices fit the problem.

Only show features you have run. Every team member should be able to explain one relationship, one query and one security decision. Mention your limits, for example the date of your data, rounding, or features you did not finish. Send your peer evaluation privately to your instructor; do not put it in the repository.

## Worked example

Work in the [capstone](../../capstone/README.md) folder and use `work.md` as your checklist.

## Your project schema

If your project uses the course data, show the `province`, `district` and `commune` tables and any tables you added. If it uses a different dataset, show your own tables or collections, columns, types and keys in your project README and in the demo.

## Lab tasks

1. Ask a teammate to set up your project from a fresh clone, using only your README.
2. Show your ERD, normalized schema, import script and data source.
3. Demonstrate your SQL reports, database objects and a parameterized query in your app.
4. Demonstrate your MongoDB pipelines and a Redis cache miss and hit.
5. Submit the report, demo outline, contribution log and output files, and answer your instructor's questions.

## Homework

1. Write an individual reflection: what you built and what you would improve.
2. Follow your instructor's instructions for the final submission and the private peer evaluation.

## Capstone sprint

**Final:** Hand over a repository that others can run, with the data source, report, demo and contribution log.

## Submit

Write your answers in `work.md` and label each one, for example a heading such as `## Lab 3`. Answer the questions in `reflection.md` and save your query output in `results/`. Then commit and push to your repository. See [SUBMISSIONS.md](../../SUBMISSIONS.md) for details.
