# Week 15: Capstone presentation and handover

> Printable version: [README.pdf](README.pdf)

**Learning outcomes:** CLO1–CLO6

## Lesson

- Demo order: question → data source → query → result. Explain your design choices.
- Show only what you ran. Each member explains one relationship, one query and one security decision.
- State limits: data date, rounding, unfinished features.
- Send peer evaluation privately to your instructor, not in the repository.

## Lab tasks

1. Have a teammate set up the project from a fresh clone using only your README.
2. Show ERD, schema, import script and data source.
3. Demo SQL reports, database objects and a parameterized app query.
4. Demo MongoDB pipelines and a Redis miss and hit.
5. Submit report, demo outline, contribution log and output; answer questions.

## Homework

1. Individual reflection: what you built and what you'd improve.
2. Final submission and private peer evaluation, as your instructor directs.

## Capstone sprint

**Final:** A repository others can run, with data source, report, demo and contribution log.
