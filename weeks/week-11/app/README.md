# Week 11 app

Put your code here (`crud.py` or `crud.mjs`). See [apps/](../../../apps/README.md) for examples. Use env variables for settings, parameters for every value, and only `student_work` tables.

Python (uses `.venv` from the apps guide):

```bash
.venv/bin/python weeks/week-11/app/crud.py
```

Node.js (once: install the driver here):

```bash
npm --prefix weeks/week-11/app init -y
npm --prefix weeks/week-11/app install mysql2@3.24.6
node weeks/week-11/app/crud.mjs
```

Commit `package.json` and `package-lock.json`, not `node_modules/`.
